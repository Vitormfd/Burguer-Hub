# Easy Food Hub

Sistema de gestão para restaurantes, lanchonetes e operações de food service.

**Domínio oficial:** https://easyfoodhub.com.br  
**Domínio técnico (backup):** https://burguer-hub.vercel.app

## Variáveis de ambiente

Copie `.env.example` para `.env` e preencha:

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_PUBLISHABLE_KEY`
- `VITE_SUPABASE_PROJECT_ID`
- `VITE_PUBLIC_APP_URL` — URL canônica pública (ex.: `https://easyfoodhub.com.br`)

## Scripts

```bash
npm install
npm run dev
npm run build
```
